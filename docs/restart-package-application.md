# Part 1. 문제 인식 (Problem)

## 1-1. 창업 아이템의 배경 및 필요성 (외부 환경 분석)

### 1) 사회 문제 · 경력 단절 여성 135만명

통계청 「지역별고용조사」(2023) 기준, 국내 15~54세 기혼여성 중 **경력 단절 여성은 약 135만명(16%)**이며, 이 중 30~44세가 68%를 차지합니다. 주요 사유는:

| 사유 | 비율 |
|---|---|
| 육아 | 40.4% |
| 결혼 | 27.1% |
| 임신·출산 | 22.0% |
| 가족 돌봄 | 4.8% |
| 기타 | 5.7% |

특히 **공백 3년 이상 여성의 재취업 성공률은 급감**하며, 재취업하더라도 이전 커리어와 무관한 저임금 서비스직으로 이동하는 비율이 높습니다.

### 2) 감정적·심리적 벽 (더 큰 장애물)

정량 지표를 넘어선 심층 문제:
- **자기 정체성 상실** · "나는 지금 무엇을 할 수 있는가"
- **실무 감각 소실** · 트렌드 · 도구 · 업계 문화 격변
- **연대의 부재** · 같은 처지의 동료 커뮤니티 없음
- **자기 검열** · "이력서 공백을 어떻게 설명하지?"

### 3) 기존 지원 제도의 사각지대

| 대안 | 강점 | KUME가 채우는 공백 |
|---|---|---|
| 새일센터·여성발전센터 (정부) | 접근성·저가 | 획일적 커리큘럼, 정서 회복 프로세스 없음, 실전 프로젝트 연결 부재 |
| 인강 플랫폼 (인프런·클래스101) | 콘텐츠 다양성 | 완주율 낮음(평균 15%), 커뮤니티·피드백 없음 |
| 사설 창업 스쿨 (신사임당스쿨 등) | 실전 스킬 | 여성 특화 X, 회복 프로세스 없음, 고가 |
| 여성 커리어 커뮤니티 (헤이조이스) | 네트워크 | 재교육 커리큘럼 부재, 첫 수입 연결 약함 |

**공백 요약**: 정서 회복 → 실전 스킬 → 첫 수입까지 이어지는 **통합 저니** + 여성이 여성을 돕는 편안한 톤

### 4) 정책적 기회

- **여성가족부 「제3차 경력단절여성등의 경제활동 촉진 기본계획(2025~2029)」** — 여성 재도약 지원 확대
- **고용노동부 「여성 경제활동 참여율 제고 정책」** — 국정과제
- **ESG·DEI 확산** — 기업의 여성 리더십 교육 수요 급증 (B2B 시장 확대)

## 1-2. 창업 아이템의 목적 (기회 포착)

### 우리가 하고자 하는 일

> "잠시 멈춰 있었던 당신의 이야기가 다시 시작될 시간"

KUME는 3-Layer 통합 저니로 여성들이:
1. **자신을 다시 만나고** (회복)
2. **실전 기술을 익히며** (부트캠프)
3. **첫 수입과 포트폴리오를 만들 수 있도록** (실제 프로젝트)

돕는 교육·에이전시 사업입니다.

### 사회적 미션

- **Mission**: 모든 여성이 다시 자신의 이야기를 당당하게 시작할 수 있는 세상
- **Vision**: 여성의 성장을 가장 먼저 떠올리는 브랜드 KUME
- **Core Value**: **정직** · 존중 · 지속 · 실전

### 브랜드의 뿌리 · 탈리다 쿰(Talitha koum)

KUME라는 이름은 아람어 "탈리다 쿰(여자여, 일어나라)"에서 왔습니다. 이 이름은 대표 개인의 재창업 여정과 사업의 사회적 미션을 하나로 잇는 상징적 자산입니다.

# Part 2. 실현 방안 (Solution)

## 2-1. 창업 아이템의 개발·사업화 방안

### 1) 3-Layer 통합 저니

```
Layer 1 · 회복          Layer 2 · 실전          Layer 3 · 성장
───────────           ───────────           ───────────
리부트 클래스     →    12주 부트캠프     →    KUME Studio 프로젝트
1:1 커리어 코칭                              위클리 커뮤니티
```

각 레이어는 독립 소비도 가능하지만, **통합 저니를 밟은 수료생일수록 성과가 크도록 설계**.

### 2) 5개 프로덕트 라인 (상세)

#### ① 리부트 클래스 · 8주 그룹 코스 · 480,000원 / 정원 10명

| 주차 | 내용 |
|---|---|
| 1~2주 | 나를 다시 만나기 · 정체성 워크숍 |
| 3~4주 | 강점·자원 발견 · Value & Skill Map |
| 5~6주 | 커리어 방향 설계 · 실행 가설 세우기 |
| 7~8주 | 첫 걸음 실행 계획 · 90일 액션 플랜 |

**차별점**: 커리큘럼 후반에 실전 스킬 브릿지 세션(브랜딩·디자인·인스타 실습 맛보기)을 배치해 부트캠프 진입 유도

#### ② 1:1 커리어 코칭 · 3개월 개인 세션 · 720,000원 / 월 2회

- 지금의 나 진단 (강점 발견 프레임워크)
- 가능성 있는 방향 탐색 (커리어·창업·프리랜서)
- 구체적 실행 계획 (90일 스프린트)
- 정서적 지지와 동행

#### ③ 위클리 커뮤니티 · 월 39,000원 구독

- 온라인 위클리 체크인 (매주)
- 월 1회 오프라인 밋업
- 주제별 소그룹 스터디 (자율 운영)
- 선배 멤버 멘토링

#### ④ 12주 브랜딩·디자인·웹 부트캠프 · 1,980,000원 (얼리버드 1,380,000원) · 정원 8명

경단녀가 재택으로 첫 수입을 만들 수 있는 실전 기술 부트캠프:

| 구간 | 내용 |
|---|---|
| 1-2주 | 브랜딩 사고법 · 좋은 브랜드란 무엇인가 |
| 3-4주 | Figma · 디자인 기초 · 실무 도구 숙련 |
| 5-6주 | 웹사이트 제작 (노코드 + 간단한 코드) · 첫 포트폴리오 |
| 7-8주 | 소셜 콘텐츠 · 인스타 그리드 기획 |
| **9-10주** | **실제 클라이언트 1인 배정 · 실전 프로젝트** |
| 11-12주 | 포트폴리오·프리랜서 수임 방법 (계약·세금·단가) |

**핵심 차별점**: 수료 후 KUME Studio 프로젝트에 실전 투입되어 첫 수입까지 책임

#### ⑤ KUME Studio · 브랜딩 에이전시

여성 창업가·1인 사업자·사회적기업 대상 브랜딩·웹·소셜 프로젝트:

| 상품 | 가격 |
|---|---|
| 소상공인 브랜딩 (로고 + 가이드) | 300만원 |
| 로고 + 웹사이트 | 500만원 |
| 통합 브랜딩 (로고 + 웹 + 인스타 3개월) | 800~1,000만원 |
| **프로보노 브랜딩** (연 2건 · 저소득·한부모 여성 창업가) | 무상 |

**이중 임팩트**: 여성 수료생 실전 경험 + 여성 클라이언트 성장 지원

| 교훈 | 요벨에서의 부족 | KUME에서의 실천 |
|---|---|---|

| **2. 팀 확장은 매출 뒤에** | 매출 앞서 인력 채용 · 고정비 부담 | 첫해는 대표 1인 + 프리랜서 강사 풀 · M7 이후 파트타임부터 |
| **3. 원가·손익 실시간 관리** | 사후 결산 · 문제 인지 늦음 | 프로젝트별·프로그램별 손익 실시간 추적 · 월 대시보드 |

### 4) 재창업의 정당성 · "왜 다시 KUME인가"

- **개인 회복**: 무너진 시간을 극복하고 있는 창업자로서, 같은 여정을 걷는 여성들에게 진정성 있는 도움
- **사회적 가치**: 개인의 실패 경험이 사회 문제 해결(여성 재도약)의 도구가 됨
- **전문성 활용**: 브랜딩·디자인·웹 실무 경험이 KUME의 핵심 프로덕트(부트캠프·Studio)로 직접 연결
- **정직 원칙**: 실패의 아픔을 아는 사람만이 "정직한 기업만 살아남는다"를 진심으로 말할 수 있음
