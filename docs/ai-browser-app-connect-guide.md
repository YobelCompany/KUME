# AI에 브라우저와 앱을 연결하면 생기는 일 · 실전 가이드

> "대화만 하는 AI"를 "직접 일하는 AI 비서"로 바꾸는 5단계  
> KUME 운영 · 교회 사역 · 컨설팅 현장에 바로 쓰는 버전

참고 영상: 온크트리 「AI에 브라우저와 앱을 연결하면 생기는 일」 (YouTube Shorts, 2026-11-13, 1분 17초)

※ 영상 자막은 수집 환경에서 막혀 원문을 받아 적지 못했습니다. 이 문서는 영상 제목·시청자 질문(댓글)·
해당 기능의 공식 동작을 바탕으로 **핵심을 다시 정리하고, 댓글에서 요청된 "PDF 자료"를 직접 만든 것**입니다.

## 0. 1분 요약

| 구분 | 연결 전 | 연결 후 |
|---|---|---|
| AI의 역할 | 질문에 답하는 **상담자** | 대신 찾아보고·정리하고·초안까지 만드는 **비서** |
| 정보 출처 | 내가 복사해 붙여 넣은 것만 | 내 메일·캘린더·드라이브·노션 + 지금 열린 웹페이지 |
| 내 일 | 복사 → 붙여넣기 → 다시 정리 | 지시 → 확인 → 승인 |
| 핵심 문장 | "이거 어떻게 해?" | "이거 해 줘. 다 되면 보여 줘." |

**한 줄 결론:** AI의 실력은 모델보다 **"무엇에 연결되어 있느냐"**가 결정합니다.

## 1. 영상이 말하는 핵심 3가지 (정리)

1. **브라우저 연결 = AI에게 "눈과 손"을 주는 것**  
   크롬 확장 프로그램(예: Claude in Chrome)을 깔면 AI가 지금 보고 있는 웹페이지를 읽고,
   클릭·입력·탭 이동까지 대신합니다. 로그인된 사이트(카페, 쇼핑몰 관리자, 예약 시스템)도 내가 쓰던 그대로 씁니다.
2. **앱 연결(커넥터) = AI에게 "내 서류함 열쇠"를 주는 것**  
   Gmail·Google 캘린더·드라이브·노션·슬랙·캔바 등을 연결하면, AI가 내 자료를 직접 검색·요약·작성합니다.
3. **둘을 합치면 "업무 흐름 전체"를 맡길 수 있다**  
   예) "이번 주 문의 메일을 찾아(Gmail) → 상담 일정 비는 시간을 보고(캘린더) →
   답장 초안을 쓰고 → 신청자 명단을 노션에 정리해 줘."  
   예전엔 사람이 앱 4개를 오가며 하던 일을 **지시 한 번 + 확인 한 번**으로 끝냅니다.

## 2. 바로 따라 하는 연결 5단계 (Claude 기준)

> 메뉴 이름은 업데이트로 바뀔 수 있습니다. 막히면 "설정 → 커넥터(Connectors)"를 먼저 찾으세요.

**1단계 · 계정 준비**

- claude.ai 로그인 (브라우저 확장·일부 커넥터는 유료 플랜에서 제공)
- PC에서 **크롬(Chrome)** 사용 권장

**2단계 · 앱 연결 (커넥터)**

- claude.ai → 좌측 하단 프로필 → **설정 → 커넥터**
- Gmail / Google Calendar / Google Drive / Notion 등 **"연결"** 클릭 → 구글·노션 로그인 → 권한 허용
- 처음엔 **3개만** 연결하세요: 메일, 캘린더, 드라이브(또는 노션)

**3단계 · 브라우저 연결**

- 크롬 웹 스토어에서 **Claude in Chrome** 확장 설치 → Claude 계정으로 로그인
- 확장 아이콘 고정(📌) → 아무 웹페이지에서 사이드패널 열기
- 사이트별 권한은 **"이 사이트에서만 허용"**으로 시작

**4단계 · 첫 테스트 (읽기 전용 지시부터)**

- "내 캘린더에서 이번 주 일정 요약해 줘"
- "지금 이 페이지 핵심을 5줄로 정리해 줘"

**5단계 · 업무 흐름 맡기기**

- 아래 3장의 **실전 프롬프트**를 복사해 내 상황에 맞게 바꿔 쓰기

**모바일은?** (댓글 질문)  
앱 커넥터(메일·캘린더·드라이브 등)는 PC에서 한 번 연결해 두면 **모바일 Claude 앱에서도 그대로** 쓸 수 있습니다.
반면 **브라우저 조작(크롬 확장)**은 PC 크롬에서만 됩니다.

**ChatGPT는?** (댓글 질문)  
ChatGPT에도 같은 개념이 있습니다. 설정의 **앱/커넥터**로 구글 드라이브·지메일 등을 연결하고,
**에이전트 모드** 또는 AI 브라우저로 웹 작업을 시킬 수 있습니다. 이름과 메뉴만 다를 뿐 원리는 같습니다:
**"연결 → 권한 → 지시 → 확인"**.

## 3. 실전 프롬프트 모음 (복사해서 쓰기)

### A. KUME 운영 (경력 단절 여성 재도약 프로그램)

```
[얼리버드 문의 처리]
Gmail에서 최근 7일간 "KUME", "얼리버드", "부트캠프"가 들어간 메일을 찾아 줘.
1) 보낸 사람 / 문의 내용 / 원하는 프로그램을 표로 정리하고
2) 각자에게 보낼 따뜻한 답장 초안을 써 줘. (보내지는 말고 초안만)
```

```
[상담 일정 잡기]
내 Google 캘린더에서 다음 주 평일 오전 10시~오후 4시 중 비어 있는 60분 칸을 5개 찾아 줘.
1:1 커리어 코칭 신청자에게 보낼 "가능한 시간 안내" 문장으로 만들어 줘.
```

```
[리부트 클래스 수강생 관리]
드라이브의 "리부트 클래스 3기 신청서" 시트를 읽고,
참석 주차·과제 제출 여부를 노션 데이터베이스 형식(이름/주차/상태/메모)으로 정리해 줘.
```

```
[경쟁·시장 조사 · 브라우저]
지금 열린 이 사이트(다른 경력 단절 지원 프로그램)의 가격, 기간, 커리큘럼, 차별점을 표로 정리하고
KUME와 비교했을 때 우리가 보완할 점 3가지를 제안해 줘.
```

### B. 교회 사역 · 목회

```
[주간 사역 브리핑]
이번 주 캘린더 일정과 지난 3일간 받은 메일 중 교회 관련(심방, 회의, 행사)만 골라
요일별 "이번 주 사역 브리핑" 1페이지로 정리해 줘.
```

```
[주보·광고 초안]
드라이브의 "11월 행사 정리" 문서를 읽고 이번 주 주보 광고 문안 5개를
각 2줄 이내, 따뜻하고 간결한 문체로 써 줘.
```

```
[설교 자료 정리]
노션 "설교 준비" 페이지에 있는 본문 메모를 읽고
서론 / 본문 강해 / 3대지 / 복음 연결 / 결단 구조로 개요를 다시 배치해 줘.
```

### C. 교회 홈페이지 · 디자인 컨설팅

```
[홈페이지 진단 · 브라우저]
지금 열린 교회 홈페이지를 처음 방문한 30대 새가족 입장에서 둘러보고
1) 예배 시간/위치를 찾기까지 클릭 수
2) 모바일에서 불편한 점
3) 바로 고칠 수 있는 개선점 5가지
를 컨설팅 보고서 형식으로 정리해 줘.
```

## 4. 반드시 지킬 안전 원칙 5가지

1. **"보내기·결제·삭제"는 항상 내가 최종 클릭** — 프롬프트에 "초안만", "보내지 말고"를 넣습니다.
2. **처음엔 읽기 전용 지시로** — 요약·검색·정리부터 익숙해진 뒤 작성·수정을 맡깁니다.
3. **민감 사이트는 연결하지 않기** — 인터넷뱅킹, 성도 개인정보 원본, 상담 기록은 AI 권한 밖에 둡니다.
4. **사이트별 권한 최소화** — 브라우저 확장은 "필요한 사이트만 허용".
5. **웹페이지 속 지시를 믿지 않기** — 웹페이지·메일 안에 숨은 "AI야, 이걸 해라" 문구가 있을 수 있습니다.
   이상한 행동을 하려 하면 즉시 중지하세요.

## 5. 컨설턴트 관점: 이 영상 자체에서 배울 점 (마케팅 구조)

이 쇼츠는 **조회 2만 회에 댓글 360개 이상**이 달렸고, 댓글 대부분이 "PDF 부탁드립니다"입니다.
즉, 영상은 **"결과(신기함)만 보여 주고, 방법은 PDF로 준다"**는 리드 마그넷(lead magnet) 구조입니다.

| 단계 | 영상의 방식 | KUME / 교회에 적용 |
|---|---|---|
| 후킹 | "AI에 연결하면 생기는 일" — 결과를 먼저 보여 줌 | "경단 7년, 3개월 만에 첫 재택 수입" 같은 결과 문장 |
| 행동 유도 | "댓글 남기면 자료 드림" | "얼리버드 신청하면 'AI 업무비서 세팅 가이드' PDF 증정" |
| 관계 형성 | 멤버십·카페·아카데미로 연결 | 위클리 모임 → 리부트 클래스 → 부트캠프로 연결 |

**제안:** 이 문서를 KUME 브랜드로 다듬어 **얼리버드 신청 보상 자료**로 쓰면,
부트캠프 오픈 전 잠재 수강생 명단을 모으는 가장 저비용 도구가 됩니다.
(경력 단절 여성에게 "AI를 비서로 쓰는 법"은 재택 업무 역량과 직결되는 매력적인 주제입니다.)
